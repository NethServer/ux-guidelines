# Avatar

Avatars represent a person or a company with an image, initials or an icon.

Code: `NeAvatar` · [Storybook](https://nethesis.github.io/vue-components/?path=/docs/components-neavatar--docs) · [Figma](https://www.figma.com/design/ZRZzzlqb9GfB9Xdz6iGufh/NDS?node-id=204-1635)

## Types and sizes

- Types: circle, circle with a status dot at the bottom, square, initials and image.
- Sizes: 24, 32, 40, 48, 56, 64, 80 and 92 px.

## Uses

- **Companies:** use the circle type with the buildings icon, for example in the phonebook.
- **Calls in the phone island:** use the circle type for every call.
- **Conferences, video calls and screen sharing:** use the initials when the person has no image.
