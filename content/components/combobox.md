# Combobox

Comboboxes let users choose from a long list of options that they can search.

Code: `NeCombobox`, `NeMultiselectCombobox` · [Storybook](https://nethesis.github.io/vue-components/?path=/docs/components-necombobox--docs) · [Figma](https://www.figma.com/design/ZRZzzlqb9GfB9Xdz6iGufh/NDS?node-id=109-897)

## Combobox or checkbox

Use a combobox when there are more than six options, or when users need to search or filter the list. With fewer options, use [checkboxes](?page=checkbox).

## Selected values

In a multiple selection, the selected values appear as squared [badges](?page=badge) that users can remove.

## Several values

When users choose how many values to add, such as the records of an object, repeat the combobox and add a button such as *Add record* below. The first value is required, and each combobox takes one choice.
