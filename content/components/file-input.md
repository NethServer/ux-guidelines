# File input

File inputs let users upload a file, by dragging it or by choosing it.

Code: `NeFileInput` · [Storybook](https://nethesis.github.io/vue-components/?path=/docs/components-nefileinput--docs) · [Figma](https://www.figma.com/design/ZRZzzlqb9GfB9Xdz6iGufh/NDS?node-id=216-20212)

## Text

- The label says clearly what kind of file users must upload.
- The label includes the file requirements, such as the accepted formats: `Backup file (*.tar.gz, *.tar.gz.gpg, *.bin)`.
- After the upload, the field shows the name of the file.
